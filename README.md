# Vue 3 + TypeScript + Vite + Red5

Introduce live video streaming features into your Vue 3 application with this Red5 HTML SDK integration.
Fork this repository to use examples of how you can integrate real-time streaming capabilities into your Vue application and accelerate development with Red5-powered workflows. Red5 HTML SDKs can be used with either of our live streaming solutions:

- [Red5 Cloud](https://www.red5.net/docs/red5-cloud/) – a fully managed streaming platform. Deploy real-time streaming in the public cloud without managing infrastructure, scaling, monitoring, or performance optimization.
- [Red5 Pro](https://www.red5.net/docs/red5-pro/) – a self-hosted live streaming server software. Deploy it on-premises, in closed networks and air-gapped environments, in public or private clouds, or in hybrid deployments.
Interested in using this integration with your Vue application? [Contact us](https://www.red5.net/contact/) to discuss your requirements and deployment goals.


Learn more about the recommended Project Setup and IDE Support in the [Vue Docs TypeScript Guide](https://vuejs.org/guide/typescript/overview.html#project-setup).
